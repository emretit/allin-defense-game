# VIS-706/708/813/814 Human Review Gate

Date: 2026-08-25

Status: Prepared; awaiting human sign-off

This gate records the remaining subjective checks that automation cannot honestly close: ambience masking/loudness, speaker/headphone fatigue, audio-only and visual-only understanding, final video review, VoiceOver/assistive-tech behavior and blind recognition.

## Evidence package

- Audio automation: `docs/evidence/runtime/audio-visual-acceptance-20260825.txt`
- Final visual stamp: `vis812-final-20260825-210559`
- Grayscale final set: `docs/evidence/visual-development/vis813-accessibility-grayscale-contact-sheet-2026-08-25.png`
- Before/after comparison: `docs/evidence/visual-development/vis814-before-after-contact-sheet-2026-08-25.png`
- Visual audit metrics: `docs/evidence/visual-development/vis813-814-visual-audit-report-2026-08-25.json`
- Sign-off template: `docs/evidence/visual-development/human-review-signoff-template-2026-08-25.json`

## Review protocol

1. Copy the template to a dated file such as `docs/evidence/visual-development/human-review-signoff-2026-08-25.json`.
2. Fill `reviewer`, `reviewDate`, playback devices, assistive-tech device and final video path.
3. Listen on device speaker and headphones at Silent, Low and Normal settings.
4. Review the same accepted run as audio-only, visual-only and normal audio+visual.
5. Inspect the final grayscale sheet for color-independent readability.
6. Run a real VoiceOver or assistive-tech pass on the installed iOS build.
7. Run the blind-recognition pass for actor/building/state silhouettes.
8. Set a flag to `true` only when the matching check passes.

## Validator

Use this command while the file is still pending:

```sh
python3 tools/validate_visual_human_signoff.py docs/evidence/visual-development/human-review-signoff-template-2026-08-25.json --allow-pending
```

Use this command for the final sign-off file:

```sh
python3 tools/validate_visual_human_signoff.py docs/evidence/visual-development/human-review-signoff-2026-08-25.json
```
